# Проверка курса

- Интерактивная программа содержит 67 уроков и проектов в 12 треках.
- Для новых уроков подготовлены теория, пример кода, практические задания с критериями и подсказками, граничные случаи, типичные ошибки и контрольные вопросы.
- Данные `index.html` синхронизированы с `curriculum.json`; новые уроки имеют отдельные Markdown-файлы в `content/lessons/t1/`.
- Интерфейс переведён на светлую тему; навигация объединена в закреплённую боковую панель; для фрагментов C++ добавлена цветовая подсветка ключевых слов, типов, строк, чисел, комментариев и операторов.
- Предыдущая версия курса проходила проверку JavaScript синтаксиса Node.js и компиляцию 26 фрагментов C++20; после текущих изменений повторная автоматическая проверка всей страницы ещё не завершена.
- Курс остаётся развиваемой учебной базой. Наличие продвинутых тем не означает автоматической готовности к Senior: нужны самостоятельные проекты, тесты, ревью и обоснование инженерных решений.
