# Указатели, арифметика указателей и const

- **Трек:** Основы программирования и C++
- **Модуль:** Язык C++: синтаксис и функции
- **Тип:** урок
- **ID:** `T1-M3-L4`

## Цель и критерий перехода

Отличать адрес от значения и доказывать, что указатель указывает на живой объект.

## Теория

Указатель хранит адрес объекта или функции. `&value` получает адрес, `*ptr` обращается к объекту по адресу, а `nullptr` обозначает отсутствие указателя на объект. Перед разыменованием необходимо гарантировать, что указатель не нулевой и указывает на объект, время жизни которого ещё не завершилось.

Арифметика указателей определена внутри одного массива и на позицию сразу за его последним элементом; разыменовывать позицию за концом нельзя. Вычитание указателей допустимо для элементов одного массива. Поэтому указатель — не универсальная замена индексу или контейнеру.

`const int* p` запрещает менять `int` через `p`, но сам указатель можно переназначить. `int* const p` запрещает переназначать указатель, но разрешает менять объект. `const int* const p` запрещает оба действия через эту переменную. Предпочитай ссылки для обязательных аргументов и умные указатели для выражения владения динамическим объектом.

## Разобранный пример

```cpp
int values[] = {10, 20, 30};
int* p = values;
std::cout << *p << '\\n';       // 10
std::cout << *(p + 2) << '\\n'; // 30

const int* readOnly = values; // менять значения через него нельзя
int* const fixedAddress = values; // нельзя переназначить указатель
```

## Практика

1. **Задача:** Напиши функцию поиска максимума, принимающую `const std::vector<int>&`.
   - **Критерий проверки:** Функция не копирует вектор и не меняет его.
   - **Подсказка:** Ссылка выражает обязательный объект, `const` — запрет изменения через параметр.

2. **Задача:** Найди в учебном примере висячий указатель и объясни, где заканчивается время жизни объекта.
   - **Критерий проверки:** Указана конкретная операция, после которой обращение недопустимо.
   - **Подсказка:** Проверь локальные переменные и `delete`.

## Граничные случаи

- nullptr; висячий указатель; выход за границу массива; разыменование после освобождения.

## Типичные ошибки

- Разыменовывать `nullptr`.
- Возвращать адрес локальной переменной.
- Считать, что `const` делает сам объект глобально неизменяемым.
- Вычислять адреса за пределами одного массива.
