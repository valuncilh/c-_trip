## Цель и критерий перехода

Объяснить контракт, инварианты, компромиссы и тесты; показать корректность на граничных случаях.

## Теория

Ветвление выбирает действие на основе условия. Цикл повторяет действие, пока условие продолжения истинно. Для корректного цикла нужны инвариант и мера прогресса. Инвариант описывает, что остаётся истинным на каждой итерации. Мера прогресса показывает, почему цикл завершится.

При поиске минимума инвариант может быть таким. После обработки первых `i` элементов переменная `minimum` хранит минимум обработанной части. Для пустого массива нужен отдельный контракт, потому что обратиться к первому элементу нельзя.

Для последовательности длины `n` индексы идут от `0` до `n - 1`. Условие `i <= n` обычно ошибочно при индексации, так как включает правую границу.

## Разобранный пример

```cpp
#include <stdexcept>
#include <vector>

int minimum(const std::vector<int>& values) {
    if (values.empty()) {
        throw std::invalid_argument("empty range");
    }
    int result = values.front();
    for (std::size_t i = 1; i < values.size(); ++i) {
        if (values[i] < result) result = values[i];
    }
    return result;
}
```

До обращения к `front()` проверяется пустой ввод. После каждой итерации `result` содержит минимум уже просмотренной части вектора.

## Практика

1. **Задача:** Посчитай положительные числа в векторе.
   - **Критерий проверки:** Пустой вектор, ноль и отрицательные значения обрабатываются верно.
   - **Подсказка:** Ноль не считается положительным.

2. **Задача:** Реализуй линейный поиск с явным результатом «не найдено».
   - **Критерий проверки:** Индекс `0` отличается от отсутствия результата.
   - **Подсказка:** Подойдёт `std::optional<std::size_t>`.

3. **Задача:** Сформулируй инвариант и меру прогресса каждого написанного цикла.
   - **Критерий проверки:** Можешь объяснить корректность и завершение.
   - **Подсказка:** Инвариант должен сохраняться от итерации к итерации.

## Граничные случаи

- Пустой ввод; off-by-one; цикл без прогресса.

## Типичные ошибки

- Не проверять пустой ввод.
- Использовать `i <= size()` для индексации.
- Не иметь меры прогресса в цикле.
