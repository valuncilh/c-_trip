## Теория

`std::array<T, N>` хранит фиксированное число элементов. `std::vector<T>` хранит последовательность переменного размера в непрерывной памяти. Когда ёмкости не хватает, вектор может выделить новый участок памяти и переместить элементы. Это перераспределение памяти.

После перераспределения указатели, ссылки и итераторы на прежние элементы становятся недействительными. Удаление элемента может инвалидировать итераторы начиная с места удаления и далее. Нельзя сохранить итератор, изменить контейнер, а потом использовать старый, не сверив правила конкретной операции.

`size()` — число элементов. `capacity()` — сколько элементов контейнер обычно может хранить до следующего перераспределения. `reserve` увеличивает ёмкость, но не создаёт элементы. Индексировать разрешено только от `0` до `size() - 1`.

## Разобранный пример

```cpp
#include <vector>
int main() {
    std::vector<int> values{10, 20, 30};
    values.reserve(100);
    // size() == 3, а не 100.
    return values[2] == 30 ? 0 : 1;
}
```

Даже после `reserve(100)` выражение `values[50]` выходит за размер контейнера. Дополнительная ёмкость не означает существующие элементы.

## Практика

1. **Задача:** Удалить из вектора отрицательные числа, сохранив порядок.
   - **Критерий проверки:** Оставшиеся значения идут в прежнем относительном порядке.
   - **Подсказка:** Изучи `std::erase_if` или erase-remove.

2. **Задача:** Измени вектор после сохранения итератора и объясни правила invalidation.
   - **Критерий проверки:** Не используешь итератор после гарантированной инвалидизации.
   - **Подсказка:** Не пытайся сравнивать недействительный итератор.

3. **Задача:** Сравни добавление с `reserve` и без него на нескольких размерах.
   - **Критерий проверки:** Эксперимент повторяем и не делается вывод по одному запуску.
   - **Подсказка:** Записывай размер, число повторов и конфигурацию сборки.

## Граничные случаи

- Пустой vector; индекс size(); reallocation инвалидирует ссылки/итераторы.

## Типичные ошибки

- Путать capacity с числом элементов.
- Считать, что `push_back` всегда сохраняет ссылки.
- Обращаться к `vector[size()]`.
