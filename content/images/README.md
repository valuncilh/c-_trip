# Иллюстрации курса

Markdown-рендерер поддерживает иллюстрации в формате:

```markdown
![Осциллограмма входного сигнала](./content/images/input-waveform.png)
```

Для локальных изображений используй путь относительно корня сайта и префикс `./content/images/`. GitHub Pages публикует эти файлы из каталога `content/images`. Внешние изображения допускаются только по HTTPS. Абсолютные пути вида `/content/images/file.png` не подходят для проекта, размещённого в подпути GitHub Pages.

## Требования к изображениям

- Добавляй содержательный alt-текст: он используется и как подпись, и для вспомогательных технологий.
- Не прячь в изображении единственную копию важного текста, формулы или условия задачи.
- Предпочитай SVG для простых схем, PNG для скриншотов и фотографий, WebP — для сжатых растровых иллюстраций.
- Сохраняй исходные данные или исходник диаграммы, если рисунок нужен для последующего редактирования.
- Используй только изображения, которые можно законно распространять в этом учебном репозитории; фиксируй источник и лицензию при необходимости.

Иллюстрация должна пояснять модель, алгоритм, устройство или измерение. Декоративные картинки, которые не помогают понять материал, не нужны.
