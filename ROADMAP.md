# Дорожная карта курса

## Текущая версия — 1.4.0
- 67 уроков и проектов в 12 учебных треках.
- Добавлены отдельные последовательные уроки по структуре C++-программы, операторам и преобразованиям, массивам, указателям, перегрузке функций, объектной модели, наследованию, исключениям, файловым потокам, лямбдам, контейнерам STL, строкам, шаблонам, concepts, ranges и идиомам языка.
- Интерактивная HTML-версия использует светлую тему, читабельную ширину текста, закреплённую навигацию и цветовую подсветку синтаксиса C++.
- Данные интерактивной версии синхронизированы с `curriculum.json`; новые уроки доступны и отдельными Markdown-файлами.
- Материалы сопоставлены с тематическим покрытием Metanit; в релевантных уроках добавлены внешние ссылки без копирования исходных текстов.
- В интерактивном плеере появился блок «Дополнительное чтение» с пояснением, как использовать внешний материал.
- Добавлены METANIT_MAP.md и CONTENT_AUDIT.md для прозрачности покрытия и проверки качества.

## Следующие этапы
1. Добавить эталонные решения и автоматические тесты к практическим задачам.
2. Добавить небольшие собираемые CMake-проекты после каждого крупного этапа.
3. Автоматизировать проверку ссылок, JSON-схемы, JavaScript и компиляции примеров в CI.
4. Разделить базовые требования C++20 и отдельные заметки по C++23/26 с указанием поддержки компиляторами.
5. Провести экспертную ревизию глубины продвинутого трека и критериев самостоятельной готовности.
