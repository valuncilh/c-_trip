## Теория

`std::string` владеет последовательностью байтов. `std::string_view` лишь представляет участок чужой последовательности и не продлевает время её жизни. View удобен как параметр только для чтения, но опасен как сохранённое поле, если источник может исчезнуть.

UTF-8 использует переменное число байтов на кодовую точку Unicode. Поэтому `std::string::size()` возвращает число байтов, а не число отображаемых символов. Для анализа текста нужно определить, считаешь ли ты байты, кодовые точки или графемы.

`operator>>` обычно читает токен до пробела. `std::getline` читает строку целиком. При смешивании методов нужно учитывать оставшийся символ перевода строки. Также проверяй состояние потока после чтения пользовательского ввода.

## Разобранный пример

```cpp
#include <iostream>
#include <string>
#include <string_view>

bool has_prefix(std::string_view text, std::string_view prefix) {
    return text.starts_with(prefix);
}

int main() {
    std::string name;
    std::getline(std::cin, name);
    std::cout << "Hello, " << name << '\n';
}
```

Функция читает `string_view` только во время вызова. Источник должен оставаться живым. Для долгого хранения данных потребуется собственная строка или другой владеющий объект.

## Практика

1. **Задача:** Напиши проверку префикса без копирования строк.
   - **Критерий проверки:** Пустой префикс и префикс длиннее исходной строки обрабатываются корректно.
   - **Подсказка:** Пустая строка обычно является префиксом любой строки.

2. **Задача:** Прочитай число, а затем целую строку без потери строки.
   - **Критерий проверки:** Ввод после числа не пропадает.
   - **Подсказка:** Разберись с оставшимся символом перевода строки.

3. **Задача:** Документируй счётчик UTF-8 текста.
   - **Критерий проверки:** Указано, считаются байты, кодовые точки или графемы.
   - **Подсказка:** Это разные единицы измерения.

## Граничные случаи

- UTF-8: байты не равны символам; dangling string_view; getline после operator>>.

## Типичные ошибки

- Хранить `string_view` от временной строки.
- Считать байты UTF-8 отдельными пользовательскими символами.
- Не проверять ошибку ввода.
