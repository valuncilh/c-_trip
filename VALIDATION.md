# Проверка курса

- В программе 67 уроков и проектов в 12 треках; навигация содержит все 67 ID.
- Проверены уникальность ID, наличие объяснений, примеров, задач и контрольных вопросов в данных курса.
- Рендерер Markdown поддерживает fenced code blocks, inline highlights, LaTeX через MathJax и Mermaid-диаграммы; внешние библиотеки нужны для отрисовки формул и диаграмм.
- Добавлена функция подсветки C++ и shell-кода; ранее рендерер вызывал отсутствовавшую функцию highlightCode, что могло ломать первый рендер урока.
- index.html и curriculum.json должны содержать идентичные данные курса. GitHub Actions проверяет JSON, число уроков, уникальность ID и синтаксис JavaScript.
- Объяснения исходной версии в среднем около 836 символов (без примера и заданий); первые базовые материалы дополнены инженерным разбором и формулами, но нужна последовательная редакторская переработка остальных уроков. Требуется последовательная редакторская переработка и проверка на реальных учащихся.
- Редактор сохраняет черновики только в локальном браузере. Он не публикует изменения в репозитории автоматически; для передачи материала используется экспорт Markdown.
- Предыдущие проверки компиляции 26 фрагментов относятся к более ранней версии; после обновлений нужна повторная компиляция всех копируемых примеров.
