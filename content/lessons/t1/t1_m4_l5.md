# Лямбда-выражения, функциональные объекты и std::function

- **Трек:** Основы программирования и C++
- **Модуль:** Объектная модель и стандартная библиотека
- **Тип:** урок
- **ID:** `T1-M4-L5`

## Цель и критерий перехода

Понимать время жизни захваченных данных и выбирать самый простой вызываемый тип.

## Теория

Лямбда-выражение создаёт объект замыкания — объект с оператором вызова, который может хранить захваченные значения. Захват `[x]` хранит копию `x`; захват `[&x]` хранит ссылочный доступ к внешней переменной. Ссылка должна оставаться действительной при каждом вызове лямбды. Особенно опасно возвращать лямбду, захватившую локальную переменную по ссылке.

Лямбды часто передают алгоритмам STL как предикаты или функции преобразования. Компилятор знает конкретный тип замыкания, поэтому шаблонный параметр обычно позволяет оптимизировать вызов. `std::function<R(Args...)>` хранит вызываемые объекты единого интерфейса, но использует type erasure и может иметь дополнительную стоимость; используй его, когда действительно нужна такая гибкость хранения.

`mutable` разрешает менять копии захваченных значений внутри замыкания. Это не делает внешнюю переменную изменяемой, если захват был по значению.

## Разобранный пример

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

std::vector<int> values{1, 2, 3, 4, 5};
int limit = 3;
auto aboveLimit = [limit](int value) { return value > limit; };
int count = std::count_if(values.begin(), values.end(), aboveLimit);
std::cout << count << '\\n'; // 2
```

## Практика

1. **Задача:** Отсортируй структуры по полю `timestamp` через лямбду-компаратор.
   - **Критерий проверки:** Компаратор задаёт строгий слабый порядок.
   - **Подсказка:** Сравнивай поле, не вычитай значения друг из друга.

2. **Задача:** Найди лямбду, захватившую локальную переменную по ссылке и живущую дольше неё.
   - **Критерий проверки:** Время жизни захвата исправлено без неопределённого поведения.
   - **Подсказка:** Реши, должна ли лямбда хранить копию значения.

## Граничные случаи

- Висячий захват по ссылке; изменяемый захват; лишняя type erasure.

## Типичные ошибки

- Захватывать всё через `[&]` без анализа времени жизни.
- Считать, что `std::function` бесплатен во всех случаях.
- Менять состояние в компараторе сортировки.
