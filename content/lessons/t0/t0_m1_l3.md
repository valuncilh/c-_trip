# Компиляция и линковка

- **Трек:** Инструменты и инженерная дисциплина
- **Модуль:** Рабочая среда
- **Тип:** урок
- **ID:** `T0-M1-L3`

## Цель и критерий перехода

Объяснить контракт, инварианты, компромиссы и тесты; показать корректность на граничных случаях.

## Теория

Препроцессор обрабатывает `#include` и макросы. Компилятор проверяет исходный код и создаёт объектный файл. Линкер соединяет объектные файлы и библиотеки, разрешая ссылки между ними. При запуске загрузчик может найти динамические библиотеки.

Ошибка компиляции обычно означает нарушение правил языка. `undefined reference` чаще указывает на проблему линковки. Функция объявлена, но её определение не попало в сборку, или её сигнатура отличается от ожидаемой.

Предупреждения компилятора нужно понимать и исправлять. Успешная сборка не доказывает корректность программы.

## Разобранный пример

```cpp
// main.cpp
#include <iostream>
int twice(int value);
int main() {
    std::cout << twice(21) << '\n';
}

// math.cpp
int twice(int value) {
    return value * 2;
}
```

Собери обе единицы трансляции: `g++ -std=c++20 -Wall -Wextra -Wpedantic main.cpp math.cpp -o demo`. Если убрать `math.cpp`, объявление останется, но определение не попадёт в бинарник.

## Практика

1. **Задача:** Разнеси программу на `main.cpp`, заголовок и реализацию.
   - **Критерий проверки:** Чистая сборка проходит одной документированной командой.
   - **Подсказка:** В заголовке оставь объявление, определение помести в один `.cpp`.

2. **Задача:** Вызови `undefined reference`, затем исправь причину.
   - **Критерий проверки:** Ты объясняешь разницу между объявлением и определением.
   - **Подсказка:** Проверь список файлов сборки и сигнатуры.

3. **Задача:** Исправь все предупреждения при строгих флагах.
   - **Критерий проверки:** Предупреждения не скрыты массовым отключением флагов.
   - **Подсказка:** Начни с `-Wall -Wextra -Wpedantic`.

## Граничные случаи

- ODR violation; старый бинарник после неудачной сборки.

## Типичные ошибки

- Путать ошибку компиляции и линковки.
- Считать успешную сборку доказательством правильного поведения.
- Отключать предупреждение без изучения причины.
