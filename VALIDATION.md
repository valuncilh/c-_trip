# Проверки и ограничения курса

## Автоматические проверки

### Интерактивный курс и материалы

Workflow `Validate course content` выполняет следующие проверки:

- `index.html` и `curriculum.json` содержат одинаковые данные курса;
- число уроков равно 67, ID уникальны, навигация содержит все ID ровно по одному разу;
- все `markdown_path` существуют;
- исходные материалы не содержат временных маркеров форматирования и метаданных `undefined`;
- относительные ссылки внутри Markdown ведут на существующие файлы репозитория;
- в статической HTML-разметке нет повторяющихся ID;
- встроенный JavaScript проходит `node --check`;
- smoke-тест Markdown-рендерера проверяет HTTPS- и относительные изображения, отклонение опасных image URL, адаптивные таблицы, формулы, fenced code blocks и экранирование HTML.

### Инженерный мини-проект

Workflow `Validate C++ projects`:

- конфигурирует CMake;
- собирает «Анализатор измерений» как C++20;
- запускает `ctest`;
- проверяет выходные поля на штатном файле;
- проверяет, что ошибочная строка отклоняется с номером строки.

## Ограничения

- Прохождение CI не означает, что все 67 уроков одинаково глубоки или что все фрагменты кода курса компилируются по отдельности.
- Часть кодовых блоков служит иллюстрацией части алгоритма и зависит от описанного вокруг неё контекста.
- Проект-анализатор имеет автоматические тесты, но они не являются всесторонним доказательством корректности для всех возможных входов или требований измерительной системы.
- Формулы LaTeX и Mermaid требуют загрузки внешних библиотек из сети. Текст и исходники диаграмм остаются в содержимом курса.
- Прогресс и черновики редактора сохраняются в текущем браузере и не синхронизируются с GitHub.
- Автоматические проверки не заменяют чтение текста специалистом и испытание курса начинающими.

## Цели редакторской проверки

- Новые термины определены до первого использования.
- Пример содержит ожидаемый результат и последовательное объяснение.
- Практические задания имеют критерии проверки, а граничные случаи названы явно.
- Таблицы, длинные строки кода, формулы и иллюстрации остаются читаемыми на мобильном экране.
- Все локальные ссылки проверяются автоматически.
- Полнота уровня Senior не заявляется без проектов, ревью и проверки практических навыков.
