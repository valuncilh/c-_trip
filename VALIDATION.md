# Проверка курса

## Структурные проверки
- 12 учебных треков и 67 уроков в curriculum.json.
- У каждого урока по 3 контрольных вопроса; точных повторов вопросов в выполненном структурном сравнении не обнаружено.
- Все уроки имеют список типичных ошибок и практические задания.
- index.html содержит встроенную копию структуры курса. При правках необходимо синхронно обновлять HTML и JSON.
- Для 17 уроков добавлены ссылки Metanit; карта тем и ограничения описаны в METANIT_MAP.md.

## Статус автоматических проверок
- В предыдущем цикле 26 фрагментов C++20 проходили компиляционную проверку, но это не означает, что каждый текущий пример уже проверен.
- Полная автоматическая проверка всех встроенных примеров после текущих изменений не подтверждена.
- Браузерная проверка LaTeX, UML и мобильной адаптации после текущих изменений ещё требуется.
- Проверка всех внешних ссылок автоматическим link checker ещё требуется.

## Следующие шаги
1. Запустить проверку JavaScript и JSON в CI.
2. Выделить собираемые примеры и проверять их через GCC и/или Clang с -std=c++20 -Wall -Wextra -Wpedantic.
3. Добавить CMake-проекты и CTest для крупных тем.
4. Проверить LaTeX и UML как при наличии сети, так и при недоступности CDN.
5. Провести экспертную проверку глубины продвинутых тем и качества задач.
6. Не заявлять о готовности к Senior только на основании количества уроков: нужны проекты, тесты, code review и аргументация компромиссов.
