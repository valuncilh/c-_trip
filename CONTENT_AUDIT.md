# Аудит учебного курса C++

## Структурный срез

Проверена структура curriculum.json версии 1.3.1 и интерактивной страницы index.html перед внесением правок версии 1.4.0.

- 12 учебных треков и 67 уроков.
- Каждый урок содержит 3 контрольных вопроса.
- В 47 уроках — по 3 практических задания, в 16 — по 2, в 4 — по 4.
- У всех уроков заполнен список типичных ошибок.
- В выполненном сравнении точных повторов контрольных вопросов не обнаружено.
- Интерактивная версия хранит данные курса внутри index.html; curriculum.json является отдельным машиночитаемым представлением. При изменении содержания оба файла необходимо синхронизировать.

Метрики подтверждают наличие структуры, но не доказывают полноту курса, корректность каждого объяснения или достаточность задач для уровня Senior.

## Исправления версии 1.4.0

## Критерий готовности урока

- [ ] Цель и предварительные знания сформулированы ясно.
- [ ] Термины определены до использования.
- [ ] Теория объясняет «почему», а не только перечисляет синтаксис.
- [ ] Пример можно собрать или его ограничения явно обозначены.
- [ ] Есть объяснение результата по шагам и типичная ошибка.
- [ ] Практика включает обычный и граничный сценарии.
- [ ] Контрольные вопросы проверяют понимание.
- [ ] Формулы и UML помогают объяснить модель, а не служат украшением.
- [ ] Внешние ссылки проверены и не заменяют авторское объяснение.
- [ ] Урок корректно отображается на узком экране.
