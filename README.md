# C++ Senior Course

Структурированный курс C++ от основ до инженерного проектирования. Включает интерактивную HTML-версию, программу курса, уроки, практические задания и исходники сайта документации.

## Быстрый старт

Откройте [`index.html`](index.html) в браузере для работы с интерактивной версией.

## Структура

- `index.html` — интерактивный автономный курс;
- `curriculum.json` — программа и метаданные курса;
- `content/lessons/` — Markdown-уроки и шаблон урока;
- `content/projects/` — шаблоны проектов;
- `site_source/` — исходники сайта документации;
- `ROADMAP.md` — дорожная карта расширения;
- `VALIDATION.md` — результаты проверок.

Курс является расширяемой учебной базой. Перед использованием как полной программы подготовки Senior следует продолжать дополнять задачи, решения и практические проекты.
