## Цель и критерий перехода

Проверять границы и выбирать между встроенным массивом, `std::array`, `std::vector` и `std::string`.

## Теория

Встроенный массив `int values[4]` содержит ровно четыре элемента с индексами от `0` до `3`. Выход за границу массива приводит к неопределённому поведению; язык не обязан автоматически сообщать об ошибке. Для фиксированного размера часто удобнее `std::array<T, N>`, а для изменяемого — `std::vector<T>`.

Двумерный встроенный массив — это массив массивов: `int grid[rows][cols]`. При обходе обычно внешний цикл проходит строки, внутренний — столбцы. Размерность является частью типа массива, а память расположена построчно.

C-строка — последовательность `char`, завершённая нулевым символом `\\0`. Сам по себе символьный массив не гарантирует наличие терминатора. В современном прикладном C++ для текста обычно выбирают `std::string`; C-строки нужны при взаимодействии с C API и низкоуровневыми интерфейсами.

## Разобранный пример

```cpp
#include <array>
#include <iostream>
#include <string>

int main() {
    std::array<int, 3> values{4, 1, 9};
    for (std::size_t i = 0; i < values.size(); ++i)
        std::cout << values[i] << '\\n';
    std::string name = "sensor-01";
}
```

## Практика

1. **Задача:** Найди сумму каждой строки матрицы `3 × 4`.
   - **Критерий проверки:** Проверены все 12 элементов; индексы не выходят за границы.
   - **Подсказка:** Внешний цикл — строки, внутренний — столбцы.

2. **Задача:** Преобразуй функцию, принимающую C-строку, в вариант со `std::string`.
   - **Критерий проверки:** Нет ручного поиска конца строки и записи за пределы буфера.
   - **Подсказка:** Используй `.size()`, `.empty()` и индексирование строки.

## Граничные случаи

- Пустой контейнер; индекс за границей; отсутствие `\\0`; размер буфера.

## Типичные ошибки

- Писать цикл `i <= array.size()`.
- Считать, что `char buffer[8]` автоматически содержит строку из восьми символов.
- Передавать массив в функцию и ожидать, что размер всегда сохранится в типе параметра.
