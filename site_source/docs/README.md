# C++ Senior Course

Учебная программа по C++20: теория, разобранные примеры, практические задачи, граничные случаи и проекты.

Откройте `index.html` в корне репозитория для автономной интерактивной версии. Полная структура программы находится в `curriculum.json`, а отдельные уроки — в `content/lessons/`.
