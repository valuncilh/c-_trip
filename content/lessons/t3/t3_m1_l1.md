# Указатели, ссылки, const и lifetime

- **Трек:** Современный C++ и ресурсы
- **Модуль:** Время жизни и объектная модель
- **Тип:** урок
- **ID:** `T3-M1-L1`

## Цель и критерий перехода

Объяснить контракт, инварианты, компромиссы и тесты; показать корректность на граничных случаях.

## Теория

Указатель хранит адрес и может быть пустым. Ссылка обозначает объект, но сама по себе не гарантирует, что объект продолжает жить. Указатель или ссылка становятся висячими, когда время жизни объекта закончилось.

Нужно отличать владение ресурсом от доступа к объекту. Сырой указатель может быть невладеющим наблюдателем. Если он должен владеть памятью, контракт становится неясным и повышается риск утечек и двойного освобождения. Большинство владельцев следует выражать через RAII-типы.

`const T*` запрещает менять объект через указатель, но сам указатель можно переназначить. `T* const` запрещает переназначать указатель, но разрешает менять объект. `const` помогает выразить намерение, но не заменяет анализ времени жизни.

## Разобранный пример

```cpp
#include <span>

int sum(std::span<const int> values) {
    int result = 0;
    for (int value : values) result += value;
    return result;
}
```

`std::span` удобнее пары «указатель плюс размер», но не владеет данными. Источник должен жить дольше использования диапазона. Для суммы также следует определить поведение при возможном переполнении.

## Практика

1. **Задача:** Найди функцию, возвращающую ссылку на локальную переменную, и исправь контракт.
   - **Критерий проверки:** Возвращаемая ссылка больше не указывает на уничтоженный объект.
   - **Подсказка:** Возвращай значение или ссылку на объект с достаточным временем жизни.

2. **Задача:** Замени пару указатель-размер на `std::span` там, где это уместно.
   - **Критерий проверки:** Пустой диапазон корректен, источник жив во время вызова.
   - **Подсказка:** Span не исправляет неверное время жизни источника.

3. **Задача:** Для каждого ресурса в упражнении назови владельца и интервал жизни.
   - **Критерий проверки:** Владение однозначно и нет скрытого `delete`.
   - **Подсказка:** Если владельца не удаётся указать, пересмотри тип данных.

## Граничные случаи

- Возврат ссылки на локальный объект; use-after-free; invalidated iterator.

## Типичные ошибки

- Возвращать ссылку на локальный объект.
- Считать `const` гарантией времени жизни.
- Использовать сырой указатель как неявного владельца памяти.
