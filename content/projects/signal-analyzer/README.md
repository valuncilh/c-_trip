# Мини-проект: анализатор измерений

**Уровень:** после основ языка, функций, контейнеров и файлового ввода-вывода  
**Стандарт:** C++20  
**Формат:** законченный пример инженерного мини-проекта с тестами

## Что построим

Консольную программу для обработки серии измерений. Каждая запись содержит одно измеренное значение. Программа проверяет файл, вычисляет минимум, максимум, среднее значение и размах, а затем печатает отчёт.

## Быстрый запуск

Из этой директории:

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
./build/signal_analyzer sample_measurements.txt
```

Примерный результат:

```text
count: 4
min: 1.180000
max: 1.310000
range: 0.130000
mean: 1.235000
```

Числа входного файла задаются по одному на строку. Пустые строки, лишний текст, повреждённые записи и файлы без измерений отклоняются. При ошибке строка с некорректным вводом указывается в сообщении.

## Из чего состоит проект

- `statistics.hpp` — структура результата и контракт функции;
- `statistics.cpp` — чистые вычисления без ввода/вывода;
- `main.cpp` — чтение и проверка файла, формирование отчёта;
- `tests.cpp` — эталонные проверки;
- `sample_measurements.txt` — вход для ручного эксперимента;
- `CMakeLists.txt` — воспроизводимая сборка C++20.

## Контракт алгоритма

Функция `calculate_statistics` принимает диапазон `double` и возвращает минимум, максимум, среднее и размах. Пустой диапазон и нечисловые/бесконечные значения приводят к `std::invalid_argument`. Вход не изменяется.

Минимум и максимум инициализируются первым фактическим измерением. Нельзя начинать обе переменные с нуля: в наборе только отрицательных значений это даст неверную статистику.

Среднее рассчитывается как сумма, делённая на количество измерений:

[
\bar{x}=\frac{1}{N}\sum_{i=1}^{N}x_i
]

Здесь (x_i) — отдельное измерение, (N) — число измерений. Размах равен (x_{max}-x_{min}). Среднее и размах описывают переданный набор значений; сами по себе они не дают погрешность или неопределённость датчика.

## Этапы самостоятельной доработки

### 1. Добавь медиану

Отсортируй копию значений либо используй `std::nth_element`. Для чётного числа измерений медиана — среднее двух центральных значений. Не меняй исходные данные внутри `calculate_statistics`.

### 2. Добавь стандартное отклонение

Выбери и документируй определение. Для описания всей данной совокупности используют делитель (N), для оценки по выборке часто используют (N-1). Эти определения нельзя смешивать.

### 3. Добавь строгий формат ввода

Поддержи комментарии, например строки, начинающиеся с `#`. Пропускай их только после явного определения грамматики файла. Некорректное значение по-прежнему должно давать номер строки и завершать программу с ненулевым кодом.

### 4. Добавь CSV-отчёт

Выведи отдельные поля с именованными колонками. Укажи единицы измерения в метаданных или заголовках, а не оставляй неясным смысл чисел.

## Тест-кейсы

Эталонные тесты проверяют:
- обычные положительные измерения;
- набор только отрицательных измерений;
- единственное значение;
- пустой диапазон;
- NaN;
- бесконечность.

Числа с плавающей точкой проверяются через численный допуск, а не оператор `==`. Применяемый в тестах допуск (10^{-9}) удобен для этих конкретных данных, но не является универсальным метрологическим нормативом.

## Критерии приёмки

- Проект собирается в режиме C++20 без расширений компилятора.
- `ctest` проходит все тесты.
- Вычисления не занимаются чтением файлов или печатью.
- Повреждённый файл не создаёт правдоподобный, но неполный отчёт.
- Формат файла, команда сборки и ограничения документированы.
- В отчёте явно сказано: описательная статистика не равна оценке точности датчика.
