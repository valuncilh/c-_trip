- **Тип:** урок

## Цель и критерий перехода

Объяснить контракт, инварианты, компромиссы и тесты; показать корректность на граничных случаях.

## Теория

Дерево состоит из узлов и рёбер без циклов. В бинарном дереве поиска ключи левого поддерева расположены до ключа узла, а правого — после него. Если вставлять отсортированные данные в несбалансированное дерево, оно может превратиться в цепочку и операции деградируют до `O(n)`.

Куча поддерживает быстрый доступ к элементу с наивысшим приоритетом. В `std::priority_queue` просмотр вершины обычно `O(1)`, а вставка и извлечение `O(log n)`. Куча не является полностью отсортированной коллекцией. Trie хранит путь по частям ключа и подходит для префиксного поиска.

Каждая структура поддерживает инвариант после операции. Для кучи родитель имеет приоритет над детьми. Для дерева поиска сохраняется порядок ключей. Тестируй удаление корня, узла с одним ребёнком и узла с двумя детьми.

## Разобранный пример

```cpp
#include <functional>
#include <queue>

int main() {
    std::priority_queue<int, std::vector<int>, std::greater<int>> ready;
    ready.push(10);
    ready.push(30);
    ready.push(20);
    return ready.top() == 10 ? 0 : 1;
}
```

Компаратор `std::greater<int>` превращает очередь приоритетов в минимальную кучу. Куча хранит не полный порядок, а только достаточный порядок для корректной вершины.

## Практика

1. **Задача:** Реализуй DFS и BFS для дерева.
   - **Критерий проверки:** Пустое дерево и дерево из одного узла обрабатываются.
   - **Подсказка:** DFS использует стек или рекурсию, BFS — очередь.

2. **Задача:** Построй дерево поиска из отсортированного массива и сравни высоту с последовательной вставкой.
   - **Критерий проверки:** Объяснена причина вырождения дерева.
   - **Подсказка:** Середина массива даёт естественную точку разделения.

3. **Задача:** Напиши trie для поиска слов по префиксу.
   - **Критерий проверки:** Различаются полное слово и совпадающий префикс.
   - **Подсказка:** Признак конца слова хранится отдельно от наличия детей.

## Граничные случаи

- Вырожденное дерево; дубликаты; удаление корня.

## Типичные ошибки

- Считать кучу полностью отсортированной.
- Не поддерживать инвариант после удаления.
- Не определить поведение для дубликатов.
