# Строки, string_view и кодировки

- **Трек:** Основы программирования и C++
- **Модуль:** Объектная модель и стандартная библиотека
- **Тип:** урок
- **ID:** `T1-M4-L7`

## Цель и критерий перехода

Различать байты, кодовые точки и пользовательские символы, а также владение и представление.

## Теория

`std::string` владеет последовательностью `char`; в типичном окружении UTF-8 эти элементы являются байтами, а не обязательно отдельными Unicode-символами. `size()` возвращает число байтов, поэтому индексирование UTF-8 строки может попасть внутрь многобайтовой кодовой точки. Для пользовательских операций над текстом могут понадобиться декодирование и библиотека Unicode.

`std::string_view` — невладеющее представление диапазона символов. Оно удобно для параметров чтения и подстрок без копирования, но не продлевает время жизни исходных данных. Нельзя возвращать view на локальную строку или хранить view после уничтожения либо изменения исходного буфера, если это делает диапазон недействительным.

Для сравнения и поиска используй методы `std::string` (`find`, `substr`, `starts_with` в C++20). Для преобразования чисел выбирай интерфейс с явной обработкой ошибок. Не смешивай байтовые длины UTF-8 и количество видимых символов.

## Разобранный пример

```cpp
#include <iostream>
#include <string>
#include <string_view>

bool hasPrefix(std::string_view text, std::string_view prefix) {
    return text.starts_with(prefix); // C++20
}

std::string label = "sensor-42";
std::string_view view = label; // не владеет данными label
std::cout << hasPrefix(view, "sensor") << '\\n';
```

## Практика

1. **Задача:** Напиши функцию, которая проверяет префикс строки через `std::string_view`.
   - **Критерий проверки:** Функция не копирует вход и не сохраняет view за пределами вызова.
   - **Подсказка:** Параметр `string_view` подходит для чтения.

2. **Задача:** Объясни, почему `size()` у UTF-8 строки не всегда равен числу букв.
   - **Критерий проверки:** Различаются байты, кодовые точки и графемы.
   - **Подсказка:** Некоторые символы кодируются несколькими байтами.

## Граничные случаи

- Пустая строка; невалидный ввод; UTF-8 символ занимает несколько байтов; висячий string_view.

## Типичные ошибки

- Возвращать `string_view` на локальный `std::string`.
- Считать каждый `char` отдельным Unicode-символом.
- Изменять строку, пока используется view на её буфер.
