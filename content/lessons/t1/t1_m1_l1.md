# Типы, значения и преобразования

> ID: T1-M1-L1 · Тип: урок

## Цель и критерий освоения

Ты умеешь прогнозировать тип выражения, обнаруживать сужающее преобразование, проверять диапазон входа и выбирать допуск при сравнении вещественных значений.

## Теория

Тип задаёт допустимые значения и операции. Типы являются частью контракта программы. Например, `std::size_t` обычно используют для размеров, но это беззнаковый тип. Вычитание большего значения из меньшего может дать большое положительное число.

Переполнение знакового целого в C++ — неопределённое поведение. Не рассчитывай на циклический переход через максимум. Вещественные числа имеют ограниченную точность, поэтому десятичная дробь вроде `0.1` обычно не представима точно в двоичном формате. Для вычислений с погрешностью применяй допуск, соответствующий масштабу данных.

Фигурная инициализация помогает обнаружить сужающее преобразование, но не заменяет проверку пользовательского ввода. Сначала проверь диапазон, затем преобразуй значение.

Для инженерного расчёта различай абсолютную и относительную погрешность. Если эталонное значение — x, а вычисленное — x̂, то:

$$
\varepsilon_{abs}=|x-\hat{x}|
$$

При x ≠ 0 относительная погрешность равна:

$$
\varepsilon_{rel}=\frac{|x-\hat{x}|}{|x|}
$$

Эти формулы помогают сравнить результат с эталоном, но допустимый предел нужно выбирать по требованиям измерительной системы.

## Разобранный пример

```cpp
int count{12};
double seconds{0.25};
double total = static_cast<double>(count) * seconds;
```

Явное преобразование показывает намерение, но не доказывает, что исходное значение допустимо. Большое целое перед переводом в узкий тип нужно проверить.

## Практика

1. **Задача:** Напиши конвертер миллисекунд в секунды с дробной частью.
   - **Критерий проверки:** Ввод `1500` даёт `1.5`.
   - **Подсказка:** Вычисляй в вещественном типе.

2. **Задача:** Отклоняй отрицательные значения и значения выше заданного предела.
   - **Критерий проверки:** Проверка происходит до преобразования типа.
   - **Подсказка:** Определи диапазон в контракте.

3. **Задача:** Сравни два `double` с допуском для маленьких и больших величин.
   - **Критерий проверки:** Ты объясняешь выбор абсолютной и относительной погрешности.
   - **Подсказка:** Один фиксированный допуск не подходит каждому масштабу.

## Граничные случаи

- Signed overflow — UB; деление на ноль; NaN; потеря точности.

## Типичные ошибки

- Ожидать точного представления любой десятичной дроби.
- Использовать signed overflow как циклический счётчик.
- Игнорировать преобразование signed и unsigned.
