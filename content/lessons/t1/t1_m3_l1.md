## Цель и критерий перехода

Уметь разделить интерфейс и реализацию и объяснить путь от исходников к исполняемому файлу.

## Теория

Программа на C++ обычно состоит из заголовков и исходных файлов. `#include` — директива препроцессора: она включает содержимое заголовка до компиляции. Заголовок объявляет интерфейс, например функцию или класс; `.cpp` содержит определения. Это позволяет нескольким исходным файлам пользоваться одним интерфейсом.

`main` — точка входа обычной исполняемой программы. Возвращаемое из `main` целое число становится кодом завершения процесса: `0` обычно означает успех. В C++ не нужно вручную писать `return 0;` в конце `main`, но явная запись может быть полезна новичку.

Используй стандартные заголовки (`<iostream>`, `<string>`, `<vector>`), а не имена внутренних файлов реализации стандартной библиотеки. Защита заголовка через `#pragma once` широко поддерживается; классический переносимый вариант — include guard через `#ifndef` / `#define` / `#endif`. Определения обычных не-шаблонных функций не следует помещать в заголовок без причины: несколько единиц трансляции могут получить повторные определения.

## Разобранный пример

```cpp
// math.hpp
#pragma once
int square(int value);

// math.cpp
#include "math.hpp"
int square(int value) { return value * value; }

// main.cpp
#include <iostream>
#include "math.hpp"
int main() {
    std::cout << square(7) << '\\n';
    return 0;
}
```

Сборка GCC: `g++ -std=c++20 -Wall -Wextra -Wpedantic main.cpp math.cpp -o demo`.

## Практика

1. **Задача:** Вынеси объявление функции вычисления площади в `geometry.hpp`, определение — в `geometry.cpp`, вызов — в `main.cpp`.
   - **Критерий проверки:** Проект собирается одной командой; заголовок не содержит дублирующего определения.
   - **Подсказка:** Подключай собственный заголовок в соответствующем `.cpp`.

2. **Задача:** Удали определение функции из сборки, оставив вызов.
   - **Критерий проверки:** Можешь объяснить ошибку линковки и отличить её от ошибки компиляции.
   - **Подсказка:** Компилятор может принять объявление, но линковщику нужно найти определение.

## Граничные случаи

- Повторное включение заголовка; несовпадающие объявления; отсутствие определения.

## Типичные ошибки

- Путать объявление функции с её определением.
- Включать `.cpp` через `#include` вместо компиляции исходных файлов вместе.
- Считать, что `#include` — это импорт модуля во время выполнения.
