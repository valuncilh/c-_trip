# Файловые потоки и форматированный ввод-вывод

- **Трек:** Основы программирования и C++
- **Модуль:** Объектная модель и стандартная библиотека
- **Тип:** урок
- **ID:** `T1-M4-L4`

## Цель и критерий перехода

Проверять состояние потока и различать текстовый формат и бинарное представление.

## Теория

`std::ifstream` читает из файла, `std::ofstream` записывает, `std::fstream` поддерживает оба направления. Проверяй успешность открытия и состояние операций. Для построчного чтения удобен цикл `while (std::getline(file, line))`: он завершится корректно при конце файла или ошибке. Конструкция `while (!file.eof())` часто приводит к обработке последней строки повторно, потому что флаг EOF выставляется после неудачной попытки чтения.

Оператор `>>` читает токены и обычно пропускает пробельные символы; `getline` сохраняет пробелы внутри строки. Форматированный вывод через `<<` удобен для текста, но не является стабильным бинарным протоколом. Не записывай структуру напрямую в бинарный файл и не рассчитывай на одинаковые padding, endianness и layout на разных платформах.

Для надёжного формата явно задай кодировку, разделители или структуру полей и обрабатывай ошибки записи. Для больших файлов можно читать потоково, не загружая всё содержимое в память.

## Разобранный пример

```cpp
#include <fstream>
#include <iostream>
#include <string>

int main() {
    std::ifstream input("measurements.txt");
    if (!input) {
        std::cerr << "Не удалось открыть файл\\n";
        return 1;
    }
    std::string line;
    while (std::getline(input, line)) {
        std::cout << line << '\\n';
    }
    if (input.bad()) std::cerr << "Ошибка чтения\\n";
}
```

## Практика

1. **Задача:** Посчитай количество строк и непустых строк в текстовом файле.
   - **Критерий проверки:** Корректно обрабатываются пустой файл и строки с пробелами.
   - **Подсказка:** Считай строки внутри цикла `getline`.

2. **Задача:** Сделай отчёт в новый файл и проверь, что запись завершилась успешно.
   - **Критерий проверки:** Ошибка открытия или записи не маскируется.
   - **Подсказка:** Проверь поток после операций записи.

## Граничные случаи

- Файл не найден; пустой файл; пробелы в строках; ошибка записи; кодировка.

## Типичные ошибки

- Использовать `while (!eof())` для чтения.
- Считать, что `operator>>` сохраняет пробелы в строках.
- Записывать бинарно сырую структуру как переносимый формат.
