# Функции: перегрузка, аргументы по умолчанию и рекурсия

## Цель и критерий перехода

Выбирать простую сигнатуру, проверять завершение рекурсии и понимать время жизни передаваемых данных.

## Теория

Перегрузка позволяет объявить несколько функций с одним именем, если их списки параметров различаются. Одного различия в возвращаемом типе недостаточно. Значения аргументов по умолчанию задаются в объявлении и упрощают частые вызовы, но чрезмерное количество перегрузок и значений по умолчанию может сделать вызов неоднозначным.

Рекурсивная функция вызывает сама себя. Для корректной рекурсии нужен базовый случай и шаг, который приближает вход к этому случаю. Глубокая рекурсия может исчерпать стек; для больших входов часто лучше цикл или явный стек.

Указатель на функцию хранит адрес функции с конкретной сигнатурой. В современном C++ для обобщаемого вызываемого объекта часто удобнее шаблонный параметр или `std::function`, но указатели на функции полезны в C API и таблицах обработчиков.

## Разобранный пример

```cpp
int area(int width, int height) { return width * height; }
double area(double radius) { return 3.141592653589793 * radius * radius; }

unsigned factorial(unsigned n) {
    if (n <= 1) return 1;       // базовый случай
    return n * factorial(n - 1);
}
```

## Практика

1. **Задача:** Перегрузи `print` для `int` и `std::string`, не используя только различие возвращаемых типов.
   - **Критерий проверки:** Вызовы однозначны и типы параметров действительно различаются.
   - **Подсказка:** Перегрузка выбирается по аргументам.

2. **Задача:** Реализуй сумму цифр числа рекурсивно и итеративно.
   - **Критерий проверки:** Оба варианта совпадают на 0, однозначных и многозначных числах.
   - **Подсказка:** Для рекурсии уменьши задачу через деление на 10.

## Граничные случаи

- Неоднозначный вызов; бесконечная рекурсия; несовпадение типа указателя на функцию.

## Типичные ошибки

- Пытаться перегрузить функцию только по возвращаемому типу.
- Забывать базовый случай рекурсии.
- Использовать рекурсию там, где глубина пропорциональна огромному входу.
