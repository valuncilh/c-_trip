# Практические проекты

Проекты связывают темы курса в работающие программы. Каждый проект должен иметь цель, ограничения, последовательные этапы, проверяемые критерии и тесты граничных случаев.

## Анализатор измерений

Первый законченный проект использует контейнеры, функции, обработку ошибок, потоки ввода/вывода, CMake и модульные тесты.

- [Описание и задания](signal-analyzer/README.md)
- [Результаты CI-проверки](signal-analyzer/VALIDATION.md)
- [Исходный код и тесты](signal-analyzer/)

Рекомендуемый порядок обучения: сначала решить задачу расчёта статистики самостоятельно, затем сравнить с эталонной реализацией и наконец добавить чтение файла.
