# Перегрузка операторов, enum и пространства имён

- **Трек:** Основы программирования и C++
- **Модуль:** Объектная модель и стандартная библиотека
- **Тип:** урок
- **ID:** `T1-M4-L2`

## Цель и критерий перехода

Использовать синтаксический сахар только там, где он сохраняет ожидаемый смысл операции.

## Теория

Перегрузка оператора позволяет задать привычную операцию для пользовательского типа. Например, `+` может складывать комплексные числа или векторы. Перегруженный оператор должен сохранять интуитивный контракт: `a + b` не должен неожиданно удалять файл или менять глобальное состояние. Не каждый оператор стоит перегружать.

`enum class` задаёт перечисление с областью видимости и без неявного преобразования в целое. Это уменьшает риск смешения несвязанных значений. Пространство имён группирует имена и помогает избегать конфликтов; в заголовках библиотек не следует писать `using namespace std;`, потому что это загрязняет пространство имён включающего файла.

## Разобранный пример

```cpp
enum class State { idle, running, failed };

namespace units {
struct Metres {
    double value;
};
Metres operator+(Metres a, Metres b) {
    return {a.value + b.value};
}
}

units::Metres distance = units::Metres{2.0} + units::Metres{3.5};
```

## Практика

1. **Задача:** Определи `enum class Status` для состояния устройства и напиши `switch` с обработкой всех вариантов.
   - **Критерий проверки:** Значения не смешиваются с произвольными целыми числами.
   - **Подсказка:** Указывай `Status::...`.

2. **Задача:** Перегрузи `==` для небольшого value-типа либо объясни, почему это не нужно.
   - **Критерий проверки:** Сравнение следует смыслу значения, а не случайным деталям хранения.
   - **Подсказка:** Сначала сформулируй контракт равенства.

## Граничные случаи

- Неестественная семантика оператора; неявное преобразование; конфликт имён.

## Типичные ошибки

- Перегружать оператор с неожиданными побочными эффектами.
- Использовать обычный `enum`, когда важна типовая безопасность.
- Добавлять `using namespace std;` в публичный заголовок.
