# Результаты проверки анализатора измерений

Проверка выполняется workflow `Validate C++ projects` на GitHub Actions.

В проверке выполняются:
1. Конфигурирование проекта CMake.
2. Сборка с требованием C++20.
3. Запуск `ctest`.
4. Запуск программы на штатном примере и проверка основных полей результата.
5. Проверка, что вход с повреждённой записью завершается ошибкой и указывает номер строки.

Проверенный запуск CI для реализации:
https://github.com/valuncilh/c-_trip/actions/runs/39821998318

Для проверенного коммита все шаги завершились успешно:
- CMake configure — passed;
- build — passed;
- test suite — passed;
- sample input smoke test — passed.

После добавления отдельного теста повреждённого ввода workflow выполняется повторно. Смотри вкладку Actions для статуса актуального коммита.

Примечание: эти результаты подтверждают сборку и перечисленные случаи, но не являются исчерпывающим анализом производительности или метрологической достоверности алгоритма.
