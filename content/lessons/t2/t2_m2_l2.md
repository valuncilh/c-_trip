## Цель и критерий перехода

Объяснить контракт, инварианты, компромиссы и тесты; показать корректность на граничных случаях.

## Теория

Граф моделирует объекты и связи. Рёбра могут быть направленными, ненаправленными и взвешенными. Список смежности обычно занимает `O(V + E)` памяти. Матрица смежности занимает `O(V²)`, но позволяет быстро проверить наличие ребра.

BFS обходит вершины по слоям и на невзвешенном графе находит кратчайший путь по числу рёбер. DFS полезен для обхода компонент и обнаружения циклов. Для графа с неотрицательными весами подходит Dijkstra. При отрицательных весах обычный Dijkstra не гарантирует правильный результат.

Граф может быть несвязным. Обход из одной вершины может не посетить изолированные вершины. Тестируй self-loop, повторные рёбра и некорректные индексы.

## Разобранный пример

```cpp
#include <queue>
#include <vector>

std::vector<int> bfs(const std::vector<std::vector<int>>& graph, int start) {
    std::vector<int> distance(graph.size(), -1);
    std::queue<int> pending;
    distance.at(start) = 0;
    pending.push(start);

    while (!pending.empty()) {
        int vertex = pending.front();
        pending.pop();
        for (int next : graph.at(vertex)) {
            if (distance.at(next) == -1) {
                distance.at(next) = distance.at(vertex) + 1;
                pending.push(next);
            }
        }
    }
    return distance;
}
```

`-1` означает, что вершина недостижима. Для API нужно заранее определить, как проверяется допустимость `start`.

## Практика

1. **Задача:** Найди число компонент связности неориентированного графа.
   - **Критерий проверки:** Учитываются изолированные вершины.
   - **Подсказка:** Запускай обход из каждой ещё не посещённой вершины.

2. **Задача:** Восстанови кратчайший путь BFS, а не только длину.
   - **Критерий проверки:** Для недостижимой цели возвращается явное отсутствие пути.
   - **Подсказка:** Храни предка каждой впервые посещённой вершины.

3. **Задача:** Выбери алгоритм для графа с отрицательными рёбрами.
   - **Критерий проверки:** Учитываются ограничения Dijkstra.
   - **Подсказка:** Рассмотри Bellman–Ford и поиск отрицательного цикла.

## Граничные случаи

- Несвязный граф; self-loop; отрицательное ребро для Dijkstra.

## Типичные ошибки

- Считать, что один обход посещает весь граф.
- Применять Dijkstra к произвольным отрицательным весам.
- Не проверять номера вершин.
