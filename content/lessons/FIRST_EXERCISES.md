# Первые упражнения

1. Собери минимальную программу командой компилятора, без IDE.
2. Добавь обработку некорректного ввода и проверь код завершения.
3. Вынеси логику в функцию с явно описанным контрактом.
4. Добавь тесты на пустой ввод, минимальное/максимальное значение и ошибочный ввод.
5. Зафиксируй изменения в Git небольшими логически завершёнными коммитами.
